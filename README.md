# HCMC Traffic A*

This project provides a roadmap for building a traffic-aware shortest-path system for Ho Chi Minh City using the A* algorithm.

## Structure

- `data/` stores raw and processed datasets
- `src/` contains the core logic for loading data, graph modeling, routing, and evaluation
- `app/` hosts the web application UI
- `experiments/` stores benchmarking outputs
- `docs/` contains reports and diagrams

## Getting started

1. Create a virtual environment
2. Install dependencies from `requirements.txt`
3. Run `python main.py`
